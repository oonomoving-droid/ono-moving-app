# 大野引越サービス｜見積システム Ver.6 PWA版

## このファイル一式について
Ver.6のHTMLアプリにインストール用マニフェスト、アプリアイコン、オフラインキャッシュを追加しています。iPhone・Android両用のWebアプリです。App Store / Google Play配布用のネイティブアプリではありません。

## 公開方法（GitHub Pages の例）
1. ZIPをパソコン上で展開します。
2. GitHubで新しい **Private ではなく Public** のリポジトリを作ります（GitHub Pagesの公開条件に応じて設定）。
3. フォルダに入っている **index.html、manifest.webmanifest、sw.js、PNG画像3枚** をリポジトリのルートへアップロードします（フォルダごと入れない）。
4. リポジトリの Settings → Pages → Build and deployment で Deploy from a branch、main、/(root) を選択します。
5. 案内された HTTPS URL（例: https://ユーザー名.github.io/リポジトリ名/）にアクセスします。公開反映まで数分かかる場合があります。
6. iPhone は Safari で開いて共有 → ホーム画面に追加（表示される場合は「Webアプリとして開く」をオン）。Android は Chrome で開いてメニュー → アプリをインストール、またはホーム画面に追加。

**大切：GitHub Pages上のアプリURLは誰でもアクセスできる可能性があります。コードやロゴは公開されます。** 顧客データはこの仕組みでは端末内（ブラウザの localStorage）に保存され、サーバーへ自動送信・同期しません。顧客個人情報を扱う業務運用ではアクセス制御、バックアップ、端末紛失対策などを別途検討してください。

## 操作・データ保存に関する注意
- 旧Ver.6の履歴は新しいPWAへ自動移行されません。旧版の「設定・バックアップ」でJSONを書き出し、新しいPWA側で「復元」してください。
- PWAをホーム画面に追加した後も、OS/ブラウザのデータ削除やアプリ削除で履歴が消える場合があります。定期的にJSONをエクスポートしてください。
- iPhoneのホーム画面アプリとSafariのタブ、AndroidのPWAと通常タブでは保存領域が異なる場合があります。データが共通と決めつけないでください。
- 初回はオンラインで開いてください。初回ロード後、キャッシュが保存された場合にオフラインで利用できます。印刷/PDF保存は各端末の印刷メニューの対応に依存します。
- 更新するときはファイル一式を再アップロードし、必要なら sw.js の CACHE 名を変更します。アプリ更新時は再表示してください。
- 公開 URLのセキュリティや顧客情報の扱いを確認するまでは、テスト用の架空の顧客情報で試してください。

## 内容物
- index.html：元のVer.6にPWA設定を追加した本体
- manifest.webmanifest：ホーム画面アプリの表示設定
- sw.js：オフライン用キャッシュ
- icon-192.png / icon-512.png：アプリのアイコン
- apple-touch-icon.png：iPhone用アイコン
